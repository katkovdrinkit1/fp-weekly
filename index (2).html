Недельная динамика по кофейням

—

Выручка по неделям, тыс. ₽

Цвет ячейки — изменение к прошлой неделе с учётом смысла статьи: для выручки и доступности рост зелёный, для ФОТ %, списаний и долгих заказов рост красный. Тренд — наклон линии за выбранный период (% в неделю для рублей, п.п. в неделю для долей). Жёлтая точка — значение вышло за ±2σ от обычного уровня этой кофейни. Итог сети: рубли — сумма, ФОТ % и списания % — отношение сумм к выручке, доступность и долгие — среднее по точкам. Недели без выручки у точки (не открыта) не учитываются.
